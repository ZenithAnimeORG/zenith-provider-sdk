# Манифест V2 и конверт пакета .zpk

Плагины для Zenith упаковываются в файлы с расширением **`.zpk`** (ZIP-архивы), которые содержат скомпилированный JavaScript-бандл, манифест метаданных, декларативную схему настроек и иконку.

Для обеспечения кроссплатформенной безопасности, моментальной установки и защиты памяти устройств Zenith проверяет физические лимиты архива и схему манифеста.

---

## Спецификация Манифеста V2 (`manifest.json`)

Каждый архив провайдера должен содержать файл `manifest.json` в корне.

### Пример `manifest.json`

```json
{
  "id": "my_anime_provider",
  "name": "Мой Аниме Провайдер",
  "version": "1.0.0",
  "sdkVersion": "0.1.0",
  "packageFormat": "zpk/v2",
  "moduleApiVersion": "1.0.0",
  "entrypoint": "index.js",
  "author": "Разработчик Сообщества",
  "description": "Быстрый поиск по каталогу и воспроизведение серий.",
  "capabilities": [
    "CATALOG",
    "MEDIA_SOURCE"
  ],
  "hosts": [
    "api.mysite.com",
    "*.cdn.mysite.com"
  ],
  "entry": {
    "js": "index.js"
  },
  "settings": "settings.json",
  "icon": "icon.png",
  "localizedNames": {
    "ru": "Мой Аниме Провайдер",
    "en": "My Anime Provider"
  },
  "localizedDescriptions": {
    "ru": "Быстрый поиск по каталогу и воспроизведение серий.",
    "en": "Fast anime catalog search and stream resolution."
  }
}
```

### Поля манифеста

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `id` | `string` | **Да** | Уникальный ID (1–128 символов, шаблон `^[A-Za-z0-9._-]+$`). |
| `name` | `string` | **Да** | Отображаемое имя в каталоге и настройках Zenith. |
| `version` | `string` | **Да** | Семантическая версия (например, `"1.0.0"`). |
| `packageFormat` | `string` | **Да** | Обязательно `"zpk/v2"` для переносимых TypeScript/QuickJS плагинов. |
| `moduleApiVersion`| `string` | Нет | Версия Module API Zenith (текущая `"1.0.0"`). |
| `sdkVersion` | `string` | Нет | Версия SDK, с которой собран плагин (например, `"0.1.0"`). |
| `entrypoint` | `string` | Нет | Путь к JS-бандлу внутри архива (по умолчанию `"index.js"`). |
| `author` | `string` | Нет | Имя или никнейм автора/команды. |
| `description` | `string` | Нет | Краткое описание возможностей. |
| `capabilities` | `string[]`| **Да** | Массив поддерживаемых возможностей. |
| `hosts` | `string[]`| **Да** | Белый список доменов для HTTP-запросов через Host Broker. |
| `settings` | `string` | Нет | Относительный путь к файлу схемы настроек `settings.json`. |
| `icon` | `string` | Нет | Путь к квадратной иконке 512x512 PNG (`icon.png`). |
| `localizedNames`| `object` | Нет | Локализованные названия по кодам языков (ru, en). |
| `localizedDescriptions`| `object`| Нет | Локализованные описания по кодам языков. |

## Список возможностей (Capabilities)

Объявляйте только те возможности, которые ваш плагин действительно реализует. Приложение Zenith использует этот список для маршрутизации запросов:

- `"CATALOG"`: Поиск по каталогу, информация о тайтле, рекомендации и списки серий.
- `"MEDIA_SOURCE"`: Источники озвучки, субтитров и прямые видеопотоки (HLS/MP4).
- `"TORRENT_SOURCE"`: Поиск торрент-релизов и magnet-ссылок для стриминга через `jlibtorrent`.
- `"SUBTITLES"`: Поиск внешних дорожек субтитров (`.ass`, `.srt`).
- `"SKIP_TIMINGS"`: Таймкоды пропуска опенингов и эндингов.
- `"POSTER_SOURCE"`: Получение качественных постеров и фонов.
- `"STREAM_EXTRACTOR"`: Разрешение сторонних видеохостингов (embed-плееров).
- `"TRACKER"`: Синхронизация отметок просмотра и статусов с профилем пользователя.
- `"IMPORT"`: Импорт пользовательских списков из файлов CSV/XML/JSON в закладки Zenith.

## Безопасность белого списка хостов (`hosts`)

Zenith контролирует **все исходящие сетевые запросы**, выполняемые через `context.fetch()`.

- Любой запрос или редирект на хост, не входящий в массив `hosts`, **немедленно блокируется** с ошибкой безопасности.
- Поддерживаются маски поддоменов (например, `"*.example.com"` подходит для `api.example.com` и `cdn.example.com`).
- Запрещено использовать широкие маски вроде `"*"` или `"http*"`: плагины с такими масками отклоняются каталогами.

```json
"hosts": [
  "myanimelist.net",
  "api.myanimelist.net",
  "*.myanimelist.net"
]
```

## Декларативные настройки (`settings.json`)

Если ваш плагин поддерживает пользовательские параметры (выбор зеркала, включение 18+ контента, API-токен), опишите их декларативно в `settings.json`. Приложение Zenith автоматически построит экран настроек в Material 3 с валидацией.

```json
[
  {
    "key": "mirror",
    "title": "Зеркало API",
    "description": "Выберите домен для запросов к каталогу и видео",
    "type": "CHOICE",
    "defaultValue": "https://api.example.com",
    "options": [
      { "value": "https://api.example.com", "label": "Основной сервер" },
      { "value": "https://backup.example.com", "label": "Резервное зеркало" }
    ]
  },
  {
    "key": "include_r18",
    "title": "Контент 18+",
    "description": "Показывать взрослые релизы в результатах поиска",
    "type": "TOGGLE",
    "defaultValue": false
  },
  {
    "key": "api_key",
    "title": "API-ключ аккаунта",
    "description": "Личный токен для авторизованных запросов",
    "type": "TEXT",
    "isSecret": true
  }
]
```

В коде TypeScript значения считываются асинхронно:

```ts
const mirror = (await context.getSetting("mirror")) || "https://api.example.com";
const includeAdult = (await context.getSetting("include_r18")) === "true";
```

## Лимиты конверта пакета (`zpk/v2`)

Для защиты устройств пользователей от zip-бомб, утечек памяти и нежелательного кода Zenith проверяет лимиты при установке пакета (`validateEnvelope()`):

| Параметр конверта | Лимит | Описание |
|---|---|---|
| **Сжатый размер пакета** | **16 МБ** | Максимальный размер файла `.zpk` на диске. |
| **Суммарный несжатый объем** | **32 МБ** | Объем всех файлов архива в распакованном виде. |
| **Размер JS-бандла** | **5 МБ** | Максимальный размер `index.js` (обычно бандл весит ~50–150 КБ). |
| **Размер manifest.json** | **256 КБ** | Максимальный размер файла манифеста. |
| **Размер settings.json** | **128 КБ** | Максимальный размер схемы настроек. |
| **Размер иконки** | **256 КБ** | Максимальный размер файла `icon.png`. |
| **Размер статического ресурса** | **2 МБ** | Максимальный размер любого отдельного ресурсного файла. |
| **Количество записей** | **100 файлов** | Максимальное число файлов внутри архива. |

### Полный запрет на исполняемые бинарные файлы

В формате `zpk/v2` скомпилированные бинарники и нативные библиотеки **строго запрещены**. Пакеты с файлами следующих расширений немедленно отклоняются валидатором:

- `.jar`, `.dex`, `.class`
- `.so`, `.dll`, `.dylib`
- `.exe`, `.apk`

Провайдеры исполняются **исключительно** движком QuickJS.

### Защита путей (Path Traversal)

Имена файлов в архиве проверяются функцией `isSafeEntryName`:
- Запрещены элементы перехода по каталогам (`..`)
- Запрещены абсолютные пути (`/` или `\`)
- Запрещены дублирующиеся имена
- Разрешены только символы: `a-z`, `A-Z`, `0-9`, `_`, `-`, `.`, `/`

## Открытая модель сообщества без подписей

Zenith использует открытую модель для авторов:
- Авторам **не требуются** сертификаты цифровой подписи, ключи разработчика или платные аккаунты.
- Каталоги сообщества используют контрольные суммы SHA-256 для проверки целостности загруженного файла.
- Безопасность гарантируется изоляцией QuickJS (64 МБ RAM), дедлайнами исполнения и шлюзом Host Broker.
